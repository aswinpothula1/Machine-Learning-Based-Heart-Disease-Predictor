# Heart Disease Prediction System

This is a machine learning project that predicts whether a person is likely to have heart disease based on medical information.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-Learn
- Streamlit

## Model Used
- Logistic Regression

## Features
- Predicts heart disease risk
- Simple web interface
- Real-time prediction

## Dataset
Heart Disease Dataset from Kaggle

## Accuracy
Model Accuracy: 80.33%
